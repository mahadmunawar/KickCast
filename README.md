# KickCast

A menu-driven console application that predicts EPL and La Liga match
outcomes (home win / draw / away win) using Elo ratings, rolling form
features and two machine-learning models.

Course: AL-2001 Programming for AI (Lab), FAST-NUCES Karachi, Fall 2026
Author: Mahad Munawar (24I-0065)

## Setup
    python -m venv venv
    (activate the venv)
    pip install -r requirements.txt
    python main.py
